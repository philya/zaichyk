# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### 2026-11-10 21:12 EET — installable `chyk` command (Claude Code, Claude Opus 5.5)

#### Added
- `pyproject.toml` with a `chyk` console script. `uv tool install .` makes `chyk <file>` available from any directory.
- Config is also read from `~/.config/chyk/.env` (`$XDG_CONFIG_HOME/chyk/.env`).
- README section on installation.

#### Changed
- `.env` is now searched from the current directory instead of the script's location. Precedence: environment variables, then `./.env`, then the user config.

### 2026-11-10 20:43 EET — back to a single model: Luna (Claude Code, Claude Opus 5.5)

#### Changed
- Removed the two-phase Jev detection. On a 10-sentence labelled test:
  - **Jev** caught 1 of 5 errors at the 0.5 threshold, and the Правопис context barely changed its scores.
  - **Luna** alone caught all 5 errors with no false positives.
- Each sentence is again sent to one model, now `MODEL` (default `~openai/gpt-luna-latest`) via OpenRouter. An identical rewrite means no error.
- The prompt now refers to the Український правопис, requires the typographic apostrophe ’, and allows replacing non-standard constructions with their normative equivalents.

#### Removed
- `DETECT_MODEL`, `DETECT_THRESHOLD`, `DETECT_BATCH_*`, `CORRECT_MODEL`, `PRAVOPYS_PATH`, the `httpx` dependency, and `tools/probe_models.py`.
- `pravopys/pravopys.md` and `tools/pravopys_to_md.py` are kept as reference, but nothing sends the Правопис to the model any more.

### 2026-11-10 20:35 EET — batch detection via the Decisions API (Claude Code, Claude Opus 5.5)

#### Changed
- Detection now uses OpenRouter's Decisions API (`/api/alpha/decisions`) instead of Chat Completions:
  - The Правопис is sent once per request as the shared `state`, and each sentence is its own `noul` question.
  - Sentences are detected in background batches, and clean sentences are skipped without stopping.
  - The cost is now per batch instead of per sentence.
- A sentence whose answer is not in yet waits for its batch. A failed batch can be retried with `[r]`.

#### Added
- `DETECT_BATCH_CHARS` (default 150000) and `DETECT_BATCH_SIZE` (default 300) set the batch limits.
- `httpx` is listed in `requirements.txt`.
- `tools/probe_models.py` sends one batched request twice and reports usage, including cached tokens.

### 2026-11-10 20:23 EET — two-phase checking with the Правопис (Claude Code, Claude Opus 5.5)

#### Added
- Two-phase checking:
  - **Detection:** a decision model (`DETECT_MODEL`, default `~typesafe/jev-latest`) returns P(error) for each sentence. Sentences below `DETECT_THRESHOLD` (default 0.5) are skipped.
  - **Correction:** only flagged sentences go to `CORRECT_MODEL` (default `~openai/gpt-luna-latest`).
- The official Український правопис (2026) as the detector's permanent context. `pravopys/pravopys.md` is generated by `tools/pravopys_to_md.py` from the PDF. `PRAVOPYS_PATH` overrides the location.
- The detector's probability is shown next to each suggestion.
- `tools/probe_models.py` checks both models and shows the raw detector response.

#### Changed
- All model calls go through OpenRouter (`OPENROUTER_API_KEY`), using the `openai` SDK instead of `anthropic`.

#### Removed
- `ANTHROPIC_API_KEY` and `ANTHROPIC_MODEL`.

### Earlier

#### Added
- Configurable model via the `ANTHROPIC_MODEL` environment variable (defaults to the latest Haiku).
- `.env` support: environment variables are now loaded from a `.env` file at startup (`python-dotenv`).
- `.env.example` documenting the expected environment variables (`ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`).
- `requirements.txt` listing project dependencies.

#### Changed
- `.gitignore` now ignores `.env` to keep secrets out of version control.
